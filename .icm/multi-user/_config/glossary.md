# Glossary — Multi-User Domain Terms

> Layer 3 · Domain terminology

- **`ADMIN_USER` / `ADMIN_PASSWORD`**: Infisical configuration values providing static administrator credentials.
- **Admin**: An authenticated user operating with administrator privileges, identified by the admin session flag or role.
- **Approval Gate**: The security requirement that self-registered accounts must be explicitly approved before accessing the application.
- **Pending Request Badge**: A visual pill/counter displayed on the Admin navbar tab indicating the number of accounts in `pending` status.
- **`pending`**: Status of a newly registered user awaiting administrator approval.
- **`approved`**: Status of a user authorized to log in, generate music, and view songs.
- **`disabled`**: Status of a previously approved user whose access has been revoked by an administrator.
- **Personal Songs**: Songs generated by the authenticated user, visible exclusively to that user unless made public.
- **Public Songs**: Songs where `is_public = 1`, making them visible in the public library tab across all authenticated users.
- **Public Toggle**: A UI toggle switch allowing the song owner or admin to change `is_public` between 0 and 1.
- **`user_id`**: The unique identifier of a user record, used to scope song and job ownership.
- **`session_token`**: High-entropy token stored in the `sessions` table and user cookie.
