## Multi-User Configuration
- **Admin Username Variable**: `ADMIN_USER`
- **Admin Password Variable**: `ADMIN_PASSWORD`
- **Default User Registration Status**: `pending`
- **Session Duration**: 7 days (604800 seconds)
- **Session Cookie Name**: `mm3_session`
- **Database Engine**: SQLite
- **Public Song Default**: `is_public = 0` (Private)
