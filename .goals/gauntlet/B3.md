# Design system — stage 03 output

Tailwind v4, CSS-first (syntax verified against v4 docs: `@theme`,
`@custom-variant`, `@source`). Palette is EXHAUSTIVE: exactly the 7 hexes
from `DESIGN.md`; derivatives are `color-mix()` of two palette colors only —
never a new hex, never a neutral gray. Built by the Tailwind CLI in the
Docker build stage: `npx @tailwindcss/cli -i web/static/input.css -o
web/static/app.css` (do not minify — the minifier folds color-mix into
foreign hexes, breaking the exhaustive check).

## The input.css contract

```css
@import "tailwindcss";
@source "../../**/*.html";   /* html/template layouts + fragments */
@source "../../**/*.go";     /* any class strings emitted from Go */

@theme static {
  --color-*: initial;        /* clears Tailwind defaults: a stray bg-red-500 cannot compile */

  /* The seven. Nothing else. */
  --color-burgundy-900: #5E1226;  /* dark canvas; light-theme headings */
  --color-crimson-700:  #A62043;  /* primary action; dark-theme borders */
  --color-crimson-600:  #B12247;  /* hover / active accent */
  --color-pearl-100:    #E5DCDF;  /* light canvas; dark-theme text */
  --color-dusty-300:    #CBBBBF;  /* lines, muted text, alt surfaces */
  --color-petrol-800:   #00486F;  /* secondary action, information */
  --color-meadow-600:   #418B1B;  /* success, ready, confirmation */

  --font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
               Helvetica, Arial, sans-serif;  /* DESIGN.md §3: system stack */
  --radius-chip: 4px; --radius-control: 8px; --radius-container: 14px;
}

/* Two themes, one attribute. Default follows prefers-color-scheme; the
 * toggle sets data-theme and localStorage. */
@custom-variant dark  (&:where([data-theme="dark"], [data-theme="dark"] *));
@custom-variant light (&:where([data-theme="light"], [data-theme="light"] *));

/* Semantic surfaces — color-mix of palette pairs, per theme. */
@theme {
  --color-surface-1: color-mix(in srgb, var(--color-burgundy-900) 94%, var(--color-pearl-100));
  --color-surface-2: color-mix(in srgb, var(--color-burgundy-900) 89%, var(--color-pearl-100));
  --color-line:      color-mix(in srgb, var(--color-burgundy-900) 76%, var(--color-pearl-100));
  --color-text-dim:  color-mix(in srgb, var(--color-pearl-100) 62%, var(--color-burgundy-900));
  --color-text-faint:color-mix(in srgb, var(--color-pearl-100) 42%, var(--color-burgundy-900));
}

@layer base {
  html { background-color: var(--color-burgundy-900); color: var(--color-pearl-100);
         font-family: var(--font-sans); }
  html[data-theme="light"] { background-color: var(--color-pearl-100);
         color: var(--color-burgundy-900); }
  /* Focus: pearl ring on dark, burgundy ring on light — always a palette
   * token, 2px at 2px offset, every interactive element. */
  :focus-visible { outline: 2px solid var(--color-pearl-100); outline-offset: 2px; }
  html[data-theme="light"] :focus-visible { outline-color: var(--color-burgundy-900); }
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after { animation-duration: .01ms !important;
      transition-duration: .01ms !important; } }
  [x-cloak]{display:none !important}
}
```

## Component specs (every value = palette token or mix of two)

- **Buttons** — `.btn` primary: bg crimson-700, hover crimson-600, text
  pearl-100 (both themes; dark theme swaps per DESIGN.md §2: bg crimson-600
  hover crimson-700). `.btn--secondary`: petrol-800 bg, pearl text. `.btn--ghost`:
  transparent, text-dim, surface-2 hover. `.btn--danger`: transparent, crimson
  border/text. Disabled: 40% opacity. One primary per view.
- **Nav bar** — surface-1 bar, sticky; brand mark + `/` + `/history` links,
  theme toggle right; active link = crimson-600 underline band.
- **Metric cards** (history header: songs generated, total minutes, last
  seed) — surface-1, 1px line border, radius-container; value H3 bold,
  label field-label; trend badge meadow (up) / crimson (down).
- **Fields** — `.input`: surface-2 bg, line border, pearl text, radius-
  control; focus per base layer. `.field-label` mono-style small caps
  (system font, 11px, letter-spaced). Lyrics textarea = `.input` +
  mono-feel tag chips row above. Range slider: crimson fill on line track,
  pearl thumb ringed crimson (webkit + moz).
- **Tag chips** — section tags as small pill buttons (radius-chip, surface-2,
  line border); hover crimson-600 border; inserted tag text rendered
  petrol-800-on-pearl inside the textarea preview only.
- **Data table** (history) — sticky header (surface-1), row hover surface-2,
  1px line row borders; numeric cells tabular-nums; row click = replay.
- **Badges** — job states: queued petrol, running crimson-600 pulse, done
  meadow, failed crimson-700; engine badge (diffusers/sglang) = info petrol
  outline. Pill shape, 16% tint bg + 45% border.
- **Audio player chrome** — native `<audio controls>` inside a `.player`
  surface-1 container: metadata line (duration · seed · engine) above,
  download + regenerate buttons below. No custom waveform in v1.
- **Progress** — `.spin` (0.7s, pearl arc) + elapsed mono timer; both
  respect reduced-motion.
- **Alerts** — 3px left border + 16% tint: success meadow, working
  crimson-600, error crimson-700; copy per blueprint §3.6.
- **Empty states** — dashed line-loud border, invitation copy, one secondary
  CTA.
- **Theme toggle** — sw-toggle pattern: knob meadow-600 when dark… pearl
  when light; persists via Alpine + localStorage `mm3-theme`.

## Typography (DESIGN.md §3)

H1 2.25rem/1.2 bold · H2 1.5rem/1.3 bold · H3 1.15rem/1.4 semibold ·
body 1rem/1.6 · small 0.85rem/1.4. System stack only (no webfont fetches —
self-contained container).
